# FIAS · Consulta Institucional de Bienes · UI v4

Versión visual alineada con el Portal de Innovación Digital FIAS y con la identidad institucional real.

La arquitectura de datos permanece sin cambios:

**Excel oficial en OneDrive/SharePoint → GitHub Actions → assets.json → GitHub Pages**

## Cambios de esta versión

- Logo oficial FIAS real en cabecera, pie y estado sin fotografía.
- Paleta azul/verde homologada con el Portal FIAS.
- Imagen real `Mapa de Activos` utilizada en el hero institucional.
- Fotografía del bien ampliada en escritorio y dispositivos móviles.
- Diseño responsivo revisado para escritorio, tablet y teléfono.
- Botones contextuales: Abrir factura, Abrir póliza y Abrir fotografía.
- Sin historial de movimientos.

Ver `README_UI_V4.md` para detalles visuales.
